# 01 - Product Principles

## Purpose
Define the non-negotiable behavior of Code Trainer before implementation decisions fragment the experience.

## First-session promise
A person with little or no coding experience can write, run, and understand a first JavaScript program in under ten minutes, reaching editable code in under 30 seconds without required signup.

## Principles
1. **The editor is the lesson.** Reading supports coding; it does not replace it.
2. **Teach one meaningful operation at a time.** Early lessons should make every line and symbol understandable.
3. **React to progress, not only pass/fail.** The system should recognize partial intent and explain the next missing piece.
4. **Never punish experimentation.** Errors are normal program states, not failures. No XP loss for struggling.
5. **Preserve real syntax.** JavaScript syntax coloring, diagnostics, formatting, and runtime behavior should feel like a real development environment.
6. **Explain the computer's state.** Show evaluated values, variables, outputs, tests, and relevant runtime state when useful.
7. **Guidance must fade with mastery.** Beginner lessons may be highly assisted; interview practice should default to restrained assistance.
8. **Teach transferable skills.** Curriculum should map to canonical skills rather than isolated lesson completion.
9. **One workspace, many modes.** Learn, Projects, and Interview share the same editor/runtime foundation.
10. **Content is replaceable.** Curriculum must be reorderable, expandable, and eventually CMS-driven without application rewrites.
11. **Reward competence and consistency, not grinding.** XP and awards reinforce real learning behaviors.
12. **Build toward real software.** The product should gradually transition from one-line exercises to authentic implementation tasks.
13. **Keep access open.** Onboarding and mastery guide recommendations; they do not hard-lock learning content.

## Experience test
At every moment a learner should be able to answer:
- What am I trying to accomplish?
- What is my code currently doing?
- What is wrong or incomplete?
- What can I try next?
