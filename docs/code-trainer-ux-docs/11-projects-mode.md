# Projects Mode UX

Projects apply learned skills to increasingly real software.

## Browser

Each project shows only essential metadata:

```text
Todo App
Intermediate
8 tasks
Skills: arrays, DOM, events
```

## Workspace

Projects reuse the editor, HUD, runtime, evaluator, and progress surfaces.

The HUD shifts from line-level instruction to task-level direction:

```text
CURRENT TASK
Render every task.

CHECKS
✓ Reads task state
✓ Creates task element
○ Displays task title

PROJECT
4 / 12 complete
```

## Guidance

The assistant should become less prescriptive as the project progresses.

Early project tasks may be guided. Later tasks should behave more like a code review partner.
