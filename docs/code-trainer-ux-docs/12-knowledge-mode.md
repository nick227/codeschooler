# Knowledge Mode UX

Knowledge tests conceptual understanding outside code production.

## Supported question types

- multiple choice
- multiple select
- true / false
- predict the output
- ordering
- matching
- identify the bug
- choose the better implementation

## Surface

Knowledge should use a focused question surface rather than the full coding workspace unless code execution is part of the question.

## Rules

- One question at a time.
- Avoid distracting score chrome during the decision.
- Explain the answer after submission.
- Tie every question to canonical skills.
- Missed concepts should influence recommendations across Learn and Interview.

## Results

Prefer concise concept-level feedback over giant score reports.
