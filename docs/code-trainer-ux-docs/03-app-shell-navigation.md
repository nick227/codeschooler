# App Shell & Navigation

## Primary navigation

```text
Home
Learn
Projects
Interview
Knowledge
Progress
```

Secondary account menu:

```text
Awards
Settings
Profile
```

## Rules

- The shell should be visually quiet inside an active challenge.
- Never expose full curriculum hierarchy inside the coding workspace.
- `Continue` should be the dominant action on Home when an active item exists.
- Current pillar and current challenge should be clear without breadcrumbs deeper than two levels.
- Mobile navigation should preserve the same information architecture, not invent a separate product model.

## Home priorities

1. Continue current work.
2. Recommended next activity.
3. Brief progress signal.
4. Entry points to the four pillars.

Avoid dense dashboards of statistics.
