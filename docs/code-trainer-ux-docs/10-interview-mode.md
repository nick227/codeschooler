# Interview Mode UX

Interview should take useful inspiration from LeetCode while reusing the Code Trainer workspace.

## Browser

Organize primarily by reusable patterns:

```text
Arrays & Strings
Hash Maps
Two Pointers
Sliding Window
Stack & Queue
Binary Search
Linked Lists
Trees
Graphs
Backtracking
Greedy
Dynamic Programming
```

Support difficulty and solved-state filtering without making filters dominate the page.

## Workspace

Problem statement, examples, constraints, editor, tests, and runtime are primary.

HUD is restrained:

```text
STATUS
7 / 9 tests passing

COMPLEXITY
Current estimate: O(n²)

HINT
Available on request
```

## Teaching policy

- Do not reveal the pattern too early.
- Prefer edge-case and complexity guidance after a working solution.
- Support guided variants for users learning a pattern for the first time.
