# Progress, XP & Rewards UX

Game mechanics should reinforce learning rather than compete with it.

## Core progress dimensions

- XP / account level
- track completion
- skill mastery
- challenge/project completion
- awards
- optional streaks

## In-workspace reward feedback

Keep partial progress small and transient without attaching XP to every evaluator transition:

```text
✓ Correct value
```

Challenge completion can be more prominent:

```text
CHALLENGE COMPLETE
+25 XP
Continue →
```

## Progress page

Prioritize:

1. What am I good at?
2. What needs work?
3. What should I do next?

Avoid turning the page into analytics for analytics' sake.

## Awards

Awards should represent meaningful accomplishments: skill mastery, project completion, debugging, no-hint runs, or sustained learning milestones.
