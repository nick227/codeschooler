# Code Trainer UX Design Pack

This package defines the UX architecture for Code Trainer around a small set of reusable surfaces, progressive disclosure, and mode-specific behavior across Learn, Projects, Interview, and Knowledge.

## Documents

1. `01-ux-principles.md` — non-negotiable UX rules
2. `02-reusable-surfaces.md` — core surface architecture
3. `03-app-shell-navigation.md` — global navigation and shell behavior
4. `04-challenge-workspace.md` — shared workspace composition
5. `05-code-editor.md` — editor behavior and syntax/diagnostics expectations
6. `06-hud-inline-assistant.md` — HUD and live teaching interaction
7. `07-runtime-panel.md` — output/tests/debug surface
8. `08-progressive-disclosure.md` — cognitive-load and reveal rules
9. `09-learn-mode.md` — guided coding trainer UX
10. `10-interview-mode.md` — LeetCode-inspired interview UX
11. `11-projects-mode.md` — project-building UX
12. `12-knowledge-mode.md` — concept-testing UX
13. `13-progress-rewards.md` — XP, mastery, awards, and feedback
14. `14-responsive-accessibility.md` — responsive, keyboard, and accessibility behavior
15. `15-ux-vertical-slice.md` — first production slice and acceptance criteria
