# Learn Mode UX

Learn is guided coding practice for true beginners through advanced language concepts.

## Feel

Closer to a game/tutorial than a professional IDE, while still using real syntax and a real editor.

## Challenge structure

```text
Goal
Starter code
Small executable task
Live progress checks
Contextual assistance
Completion reward
```

## Feedback cadence

The system should acknowledge meaningful progress at small intervals:

```text
✓ Declared variable
✓ Assigned correct value
✓ Challenge complete    +25 XP
```

Use restrained animation and no punishment for mistakes. Partial evaluator transitions are acknowledgement, not repeatable XP events.

## Beginner constraints

- One concept at a time.
- One dominant action.
- No unnecessary terminology.
- Explain syntax errors in learning language, not raw parser language when a better explanation exists.
