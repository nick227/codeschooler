# 07 - Knowledge Assessment Model

## Purpose
Measure conceptual understanding that coding challenges do not always expose directly.

## Question types
- multiple choice
- multiple select
- true / false
- predict the output
- put execution steps in order
- match term to meaning
- identify the bug
- choose the better implementation

## Topic families
### JavaScript
scope, closures, `const`/`let`, references vs values, coercion, truthiness, event loop, promises, prototypes.

### Computer Science
Big O, arrays vs linked lists, stacks, queues, trees, graphs, recursion, hashing, memory basics.

### Web
HTTP, REST, DOM, events, cookies, sessions, CORS, browser lifecycle, client/server boundaries.

## Shared skill graph
Every question references one or more canonical skills. Quiz performance updates the same mastery profile as code challenges.

## Feedback behavior
After an answer:
- show correctness
- explain why
- explain why close distractors are wrong when useful
- link to related skill review
- recommend a coding challenge if conceptual weakness persists

## Assessment modes
- **Practice:** immediate explanations and retries
- **Checkpoint:** finite set with score and mastery update
- **Interview Review:** mixed questions with restrained assistance
