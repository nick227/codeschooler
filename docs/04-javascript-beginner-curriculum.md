# 04 - JavaScript Beginner Curriculum

## Goal
Take a true beginner from typing a first line to understanding the major building blocks required to create small browser programs.

## Section 1 - Make the Computer Do Something
- type and run `console.log("Hello")`
- edit an existing string
- work with a number literal
- run two statements in sequence
- intentionally create and fix a simple syntax error

## Section 2 - Remembering Things
- create a variable
- assign strings and numbers
- print variables
- use two variables together
- understand `const` vs `let` at a practical level

## Section 3 - Expressions
- arithmetic
- string concatenation / interpolation
- comparisons
- booleans
- evaluation visualized in the HUD

## Section 4 - Decisions
- `if`
- `else`
- compound conditions
- truthy/falsy introduced only after concrete examples

## Section 5 - Functions
- call a function
- define a function
- parameters
- return values
- local scope

## Section 6 - Arrays
- create arrays
- indexing
- length
- push/remove
- iteration

## Section 7 - Objects
- create objects
- read properties
- modify state
- arrays of objects

## Section 8 - Program Behavior
- loops
- state changes
- debugging
- decomposition
- reading errors

## Section 9 - Browser JavaScript
- select elements
- update text/classes
- events
- form input
- small interactive UI

## Design constraint
The earliest challenges should be intentionally tiny. The learner should become comfortable typing, running, breaking, fixing, and understanding code before being asked to build larger artifacts.
