# 06 - Interview Curriculum

## Purpose
Train reusable reasoning patterns rather than presenting an unstructured list of LeetCode problem numbers.

## Primary sections
- Arrays & Strings
- Hash Maps / Sets
- Two Pointers
- Sliding Window
- Stack & Queue
- Binary Search
- Linked Lists
- Trees
- Heaps / Priority Queues
- Graphs
- Recursion
- Backtracking
- Greedy
- Dynamic Programming

## Pattern progression
Each pattern should move through:
1. concept visualization
2. tiny implementation exercise
3. guided easy problem
4. independent easy problem
5. representative medium problems
6. mixed recognition problems

Example: Two Pointers
- maintain two indexes
- decide which pointer moves
- sorted pair search
- remove duplicates
- container-style optimization
- rain-water-style boundary reasoning

## Interview workspace behavior
- problem statement and examples
- editable solution function
- visible test cases plus hidden checks
- runtime/complexity targets where appropriate
- optional hint ladder
- post-solve explanation and pattern classification

## Scoring dimensions
- correctness
- edge cases
- time complexity
- space complexity
- independence / hint usage as optional achievement data

Do not require one canonical solution when multiple valid approaches satisfy constraints.
