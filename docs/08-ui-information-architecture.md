# 08 - UI Information Architecture

## Primary navigation
- Home
- Learn
- Projects
- Interview
- Knowledge
- Progress

Secondary profile menu:
- Awards
- Profile
- Settings

## Pages
### Home / Dashboard
Continue current work, recommended next activity, XP/level/streak, recent mastery changes, pillar entry points.

### Learn
Track -> section -> lesson catalog with progress and prerequisites.

### Projects
Project catalog with skills, difficulty, completion, and continue state.

### Interview
Pattern-based catalog with difficulty, solved status, mastery, and optional problem filters.

### Knowledge
Concept categories, quiz sets, checkpoints, weak-topic review.

### Code Workspace
Shared execution surface for Learn, Projects, and Interview.

### Quiz Workspace
Focused question/answer environment for Knowledge.

### Progress
Account progression, track completion, skill mastery, strengths, weaknesses, activity history.

### Skill Detail
Mastery state plus related lessons, projects, interview problems, knowledge questions, and recommended next work.

### Awards
Earned and locked milestone awards.

### Settings
Editor preferences, theme, accessibility, language, assistant guidance defaults.

## UX rule
Catalog pages answer **what should I work on?** The workspace answers **do the work**. Avoid duplicating learning mechanics across pillar-specific pages.
